# 👻 Advance GhostShell AI

An offline AI assistant built with Python, Flask, and Ollama.

## ✨ Features
- AI-powered chat assistant
- Works locally using Ollama
- Dark-themed web interface
- Simple and user-friendly design
- Git command explanations

## 🛠️ Technologies
- Python
- Flask
- HTML
- CSS
- JavaScript
- Ollama
- Gemma 3 (1B)

## ⚙️ Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/abubakkarsithikm06/Advance-GhostShell-AI.git
   ```

2. Open the project folder:
   ```bash
   cd Advance-GhostShell-AI
   ```

3. Install Flask:
   ```bash
   pip install flask
   ```

4. Start Ollama and download the model:
   ```bash
   ollama pull gemma3:1b
   ```

5. Run the application:
   ```bash
   python web_app.py
   ```

6. Open in your browser:
   `http://127.0.0.1:5000`
